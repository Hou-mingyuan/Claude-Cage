# Cage v0.2.1

- 在工作台侧栏可直接新建终端、置顶项目或重命名项目。编辑另一个项目后，当前工作区会继续保持打开。
- 一台电脑可配对多台移动设备。手机可以在当前任务运行时继续发送消息，平板支持分栏显示。
- 插件可以在隔离环境中安装和启动厂商桌面应用，也可以在工作台显示可拖动的半透明浮窗。插件市场会按 Cage 版本判断功能是否可用。
- 改善高分屏上的远程桌面清晰度。独立 Claude Desktop 实例的浏览器登录回调会返回发起登录的实例。
- 首次设置时可测试加密 DNS。网络出口切换后会重新绑定网卡，工作台会提示连接状态。
- 改善已有环境磁盘的识别。读取配置遇到权限或 I/O 错误时会保留环境目录和持久磁盘。

## 下载

Mac 用户可在苹果菜单的“关于本机”确认处理器。显示 Apple 芯片时选择 `macos-arm64.dmg`，显示 Intel 处理器时选择 `macos-amd64.dmg`。Windows 使用 `windows-amd64-setup.exe`，Debian 或 Ubuntu 的 x86-64 系统使用 `linux-amd64.deb`，Android 使用 `android-arm64.apk`。每份安装包的 SHA-256 都列在同一版本的 `SHA256SUMS` 中。
