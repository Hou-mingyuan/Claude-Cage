# Cage v0.2.0-rc

这是 v0.2.0 的候选版，供愿意提前验证的用户使用。本版本是一次较大的更新：环境统一为 Debian 13，并新增插件平台与插件市场。提供 Apple Silicon macOS、Windows x64、Linux x64 和 Android arm64 安装包；当前正式版仍为 v0.1.8。

## 使用与升级

升级前保存工作、停止环境并退出 Cage，再安装对应系统的安装包。账户、收藏、代理、配置和已添加的项目继续使用；Cage 不会删除或改动旧环境的磁盘。工作台提示更新环境工具时，可在“设置 → 环境版本”中更新。

本版本不再支持创建 macOS、Windows 或 Ubuntu 环境，统一使用 Debian 13。早期创建过其他系统环境的用户，升级后首次启动会新建 Debian 环境：只保存在旧系统磁盘里的文件、工具和登录状态不会进入新环境，需要重新登录 Claude。旧磁盘仍留在原位置，确认无需保留后可自行删除以释放空间；详见[环境系统说明](https://claude-cage.com/docs/guest-systems/)。需要本机软件与桌面能力时，请改用插件。

Windows v0.1.7 用户请从本版本附件下载安装程序，退出 Cage 后手动安装；详细步骤见 [Windows 使用指南](https://claude-cage.com/docs/windows/)。

## 主要改进

- **插件平台与插件市场。** 环境里的 Claude 可以通过插件使用电脑上的工具，也可以使用运行在环境内的插件。插件可在市场中安装、更新、卸载、单独启停，并限定哪些工具可被使用；主机插件设有总开关，每次调用前确认，授权可以记住。首批插件覆盖 Word、Excel、PowerPoint 文档读写，Blender，桌面控制，浏览器，网页抓取，Git，SQLite，记忆，以及文档转 Markdown 等。缺少 `uv`、`npx` 或 `python3` 时会给出安装引导。官网新增插件市场页面（`/plugins/`），支持检索和筛选。
- **多账号共享。** 多个账号之间共享会话历史、记忆、技能、指令和钩子，可在侧栏直接用其他账号继续未打开的会话。登录凭据、插件市场令牌和组织托管内容仍按账号隔离，不会带到其他账号。
- **终端通知。** Claude Code 回合完成或等待确认时，可发送系统通知，点击后回到对应终端。默认关闭，在“设置 → 通知”中开启；通知不含提示词或回复内容，远程连接的客户端不弹通知。
- **网络。** DoH 切到备用线路后会定时回到主线路；仅在所选路线含 IPv6 地址时启用 IPv6；支持自建 Headscale 与自托管 tailnet；支持从分享链接导入节点（含 VMess gRPC、Hysteria2 多端口），并可批量测速。Cage 会拒绝把本机代理端口当作节点，旧的此类配置会保留来源并提示重新导入。出口位置可选用 ipinfo.io 作为回退，默认关闭，开启后只取国家。
- **一键换机。** “设置 → 环境与恢复”新增快速换机（原地重置设备标识）与彻底换新机（重建环境）。可逐项选择要清理的内容，默认移入恢复批次；换新机时先建好新环境，验证可用后才处理旧环境，失败会自动回滚。
- **粘贴与剪贴板。** 复制文件或文件夹后，Cage 不再在后台读取，只在 Cage 画面内粘贴时才传入环境。修复应用抢先读取剪贴板时丢失排队按键和第二次粘贴的问题，修复富文本被改写为图片的问题。
- **终端。** 终端上限只计算仍在运行的终端，已结束的终端可直接关闭；不属于任何项目的终端归入“其他终端”分组。`cage up --reset` 和 `cage login --reset` 现在会真正重建环境，无效参数会报错而不是被忽略。
- **性能。** 降低资源探测、会话发现和网络监视的开销，窗口隐藏时暂停实时网速并放缓轮询，用量统计在大量历史下明显更快，通知监听空闲时不再唤醒。
- **稳定性与平台修复。** 环境组件清单在断电或中断时不再丢失，Windows 重启后遗留的进程记录不再阻止启动；修复 Windows 构建与更新问题、macOS 云盘项目共享、Linux NVIDIA 驱动下的渲染参数、Debian 镜像选择及大量 Windows、macOS、Linux 的小问题；设置、插件市场等界面补齐多语言文案，可点选区域增大到至少 44 像素。

Claude Code 和 Claude Desktop 继续在实际下载安装时解析对应平台的官方最新版本，保留已经安装的更新版本。下载或验证失败时可以修复网络后重试。

## 验证范围

CI 已在 macOS（Apple Silicon 与 Intel）、Windows 和 Linux（Debian，以及 Ubuntu 软件包兼容性）上通过。签名、公证、构建及自动化测试的最终结果以本次发布记录为准。

以下范围未在真实设备上验证：Windows 实机的换机目录移动、macOS WebKit 的粘贴与点击、搭载 NVIDIA 显卡的 Linux 机器、真实 Headscale 服务器；插件中的桌面控制未在真实电脑上测试。完整客机创建、真实 Claude 账户授权和模型请求、重启后的恢复以及手机配对仍需要实机验收。

已知限制：

- 重建环境被中断时，旧环境会保留为归档，但不能一键恢复。
- 快速换机中途失败时，环境与主机的身份信息可能不一致，相关数据保留在恢复批次中。
- 不通过官方卸载入口、而是手动删除插件或 MCP 时，需要重复操作一次才能同步到其他账号。
- 本版本暂不支持导入 `socks://` 分享链接。

Android APK 要求 Android 8.0+，从本版本标签对应源码构建，沿用既有签名证书。本版本尚未在 Android 真机上验证，手机实机配对仍需验收。
