# Cage v0.2.2

## 在本机终端用 Claude Code

在项目目录运行 `cage claude`，就能用默认账号打开 Cage 里的 Claude Code。首次登录用 `cage login`，在 Cage 浏览器里完成 Claude 授权。在新项目启动 Claude 时，当前目录会自动加入共享项目，文件修改会写回主机。

```sh
cage claude                            # 开始交互
git diff | cage claude -p "总结改动"   # 从管道读取内容
cage account list                     # 查看账号名称、Claude 邮箱和固定 ID
cage work -p "解释这个项目"             # 本次使用名为 work 的账号
```

可以在工作台修改账号名称，也可以运行 `cage account rename 03 work` 给编号 03 的账号改名。单次指定账号会保留原来的默认选择和会话归属。裸 `cage` 显示 Cage 帮助。如果用过早期预览版，把脚本里的 `cage -p` 改为 `cage claude -p`。Claude 的参数和子命令都写在 `cage claude` 或账号名后面。[终端使用指南](https://claude-cage.com/docs/workbench/)

`cage start` 在后台启动本机服务和虚拟机。`cage stop` 和 `cage restart` 同时管理两者。停止或重启会中断正在运行的任务，请先保存工作。`cage up` 唤回工作台窗口。纯终端使用时，编辑器、远程画面和音频按需启动。隐藏窗口会暂停终端渲染，再次打开可以接回输出。

## 工作台与共享项目

- 共享项目中读取 Git 状态和大量小文件时减少了重复操作。Claude 会话暂停后，可以从原终端继续，并保留账号绑定。
- 插件桌面应用使用完整画布，支持 Retina 显示和窗口缩放。在侧栏可关闭运行中的应用；安装或更新一个应用时，仍可使用其他已就绪的应用。
- 链式代理的中转节点可以配置自动切换。Windows 改善了 Claude Desktop 的中文输入法体验，并修复了从 WPS 复制表格单元格时被当作图片的问题。

## 安装与升级

v0.2.1 用户可在工作台检查更新。请先保存工作，按提示停止环境，再从原位置升级。v0.2.2 增加了终端更新命令，`cage update --check` 检查新版本，`cage update` 执行升级。

安装 Node.js 20 或更新版本后，也可运行 `npm install -g claude-cage` 安装终端入口，然后运行 `cage version`。新电脑会获取对应的官方 Cage 安装包，已有兼容版本的电脑会使用原安装。[安装指南](https://claude-cage.com/docs/installation/)

Linux 系统包提供的命令名是 `claude-cage`，例如 `claude-cage claude`。

Mac 请按芯片选择 `macos-arm64.dmg` 或 `macos-amd64.dmg`（Intel）。Windows 使用 `windows-amd64-setup.exe`，Debian 和 Ubuntu 的 x86-64 系统使用 `linux-amd64.deb`，Android 使用 `android-arm64.apk`。安装包的校验值见本页附件 `SHA256SUMS`。
